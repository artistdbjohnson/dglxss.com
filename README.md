# dglxss.com

**what dreams may come true** — product design portfolio by dglxss.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 3
- Lucide React

## Scripts

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Structure

- `/` — hero + Work / In Progress portfolio
- `/about` — maker
- `/builds/[buildId]` — active build detail (DockProof Kit)

## Particle field

Continuous seamless canvas sky: thinner density, no concentric rings, no black-frame reset. Positions are continuous functions of time.
